# 抖音

## 视频规格

- 竖屏 9:16，**15–25 秒**（完播优先）
- 前 1 秒必须出钩子（亮灯刺眼特写）
- BGM：轻一点的 lo-fi / 无词，音量压过口播
- 字幕：大字、每行 ≤ 12 字

## 封面

文字：`MagSafe 灯能关？`
右下角小字：`开源`

## 口播脚本 A（推荐，约 20 秒）

```
（画面：关灯房间，MagSafe 橙/绿灯特写）
「睡觉最烦什么？Mac 充电器这颗灯。」

（画面：点菜单「关闭指示灯」→ 灯灭）
「系统关不掉，我开源了个小工具：暗灯。」

（画面：菜单栏图标 + 字幕）
「只关指示灯，充电不变，键盘灯也不动。」

（画面：GitHub 页 / 二维码）
「GitHub 搜 magoff，免费，链接在主页。」
```

## 口播脚本 B（更短，15 秒）

```
「MagSafe 灯，关。」
「开源工具暗灯，一键灭。」
「充电照旧。GitHub：magoff。」
```

## 拍摄 checklist

- [ ] MagSafe **带灯线**插着（没灯拍了等于白拍）
